# 春季策划落地说明

依据根目录的《thatgamejam_瓶中小调_游戏策划案_v0.1.docx》与 2026-10-26 的补充要求实现。原始策划文档只读保留，本说明记录代码中的具体规则。

## 剧情与本阶段范围

四季原本由完整乐章维持。魔法师从沉睡中醒来，发现乐章破碎，春花结冰、雨滴停滞。她把自然声音装入玻璃罐，复原春季主题，让天气恢复，并打开通向夏季的道路。最终四季主题汇合、镜头回望四季属于后续 Jam 内容。

春季完整切片是本阶段范围。夏、秋、冬保留主题、声音方向与下一关接口，尚未制作成完整关卡。继续保留已有三平台跳跃，未因策划的“不实现跳跃”缩减现有功能。

## 要求与实现

| 要求 | 当前实现 |
| --- | --- |
| 苏醒和失序背景 | 开场静止叙事与清晰主题，冰封植物、悬停雨滴、冻结道路 |
| 移动与互动 | A/D、左右方向键、空格、F 全图显现；靠近瓶子显示“按 E 收集”，仅按 E 收集 |
| 四个自然声音 | 春风、雨滴、嫩芽、鸟鸣，数据配置独立 |
| 玻璃罐栏 | 空罐与已收集罐分别显示，未显现的音符不提前显示 |
| 四拍音序器 | 点击与拖动放入、替换、交换、移除、清空和反复试听 |
| 固定节拍 | 90 BPM、一罐一拍，可从关卡配置修改；以 Web Audio 时钟排程 |
| 回忆系统 | 每轮一次模糊乐句；左上角三个圆点，消耗立即变为空心 |
| 答错反馈 | 短暂天气紊乱，尝试数递减，片段与收集状态复位隐藏 |
| 正确位置反馈 | 后续尝试的对应空槽保留微弱绿点，不替玩家保留罐子 |
| 恢复演出 | 冰层淡出、暖色与花草淡入、藤蔓道路出现、真实碰撞阻挡解除 |
| 下一季 | 需走到右侧夏季入口才完成关卡，保留 `nextLevelId` 和季节规划数据 |
| 正式素材接口 | 混乱/恢复背景层、互动点、角色四状态、玻璃罐、封路/开路与三版乐句 |
| 已有功能保留 | 跳跃、三平台、出生点、暂停、静音、重开、点击排序、试听与配置检查 |

## 补充要求的优先级

用户确认：F 一次显现本轮全部音符；三次失败后结束本关，允许重新开始。它们覆盖原策划“提示耗尽仍无限尝试”“错误不重置收集”的描述。现有功能保留原则不要求保留与本次明确规则冲突的无限提示或错误不复位行为。

开场清晰主题只自动播放一次，不计入答题窗口的三次模糊回忆。答题提示、开场主题、恢复主题使用三个独立键和文件，不通过按钮绕过次数限制。

## 圆点计数

圆点数等于 `maxAttempts - failedAttempts - 本轮是否已听回忆`，最低为零。尝试次数等于 `maxAttempts - failedAttempts`。因此听过后答错不会重复扣圆点，没听就答错也不能把本轮额度留给下一轮。

| 行为 | 剩余尝试 | 剩余实心点 |
| --- | --- | --- |
| 初始 | 3 | 3 |
| 第一轮听提示 | 3 | 2 |
| 第一轮答错 | 2 | 2 |
| 第二轮未听直接答错 | 1 | 1 |
| 第三轮听提示 | 1 | 0 |
| 第三轮再答错 | 0，进入失败界面 | 0 |

关闭或暂停不创建新轮次。新轮次只由错误提交触发；重开整关才恢复三次机会。当前默认关闭无限尝试模式，相关配置保留便于后续模式扩展。
