- `pnpm test`：10 项测试全部通过。覆盖重复拾取、未知片段、未集齐/未返回时禁止通关、答错重试、退出后保留进度、槽位交换/移除/清空、所有 24 种片段排列、无效配置、素材引用和跳跃可达性。

- `bash -n scripts/dev.sh`：脚本语法检查通过；系统 PATH 没有 Node/pnpm 时，已实际通过该脚本调用 Codex 附带运行时启动开发服务器。
