# 瓶中小调 Melody in a Jar

TypeScript + Phaser 4.2.1 + Arcade Physics + Vite 实现的 PC 横屏音乐解谜原型。本阶段交付春季完整切片：魔法师苏醒，显现并收集自然声音，用四拍音序器还原春天，恢复天气后走到夏季入口。现有的平台跳跃、暂停、重开、点击排序、试听与素材接入能力全部保留。

查找功能实现请先看 [游戏功能与代码索引](docs/GAMEPLAY_CODE_MAP.md)：按玩法列出文件、函数和配置入口。玩法函数上方有中文注释，配置类型中的关键参数也有说明。

## 当前玩法与操作

| 操作 | 输入 |
| --- | --- |
| 左右移动 | A/D 或左右方向键 |
| 跳跃 | 空格；保留已有平台玩法，长按不连跳 |
| 显现音符 | F，或 HUD 的“显现声音”；一次显现本轮全部音符 |
| 收集声音 | 靠近已显现的玻璃瓶，出现“按 E 收集”后按 E；接触或鼠标点击不会收集 |
| 打开音序器 | 集齐四只声音罐后回到左侧出生点；原地也可点击 HUD 的回忆点按钮 |
| 放入、替换、交换 | 鼠标拖动；也可点击选择片段，再点击槽位 |
| 移除槽位 | 点击已放入的声音罐，再次点击同一个槽位 |
| 演奏与重置 | 音序器内的按节拍演奏、停止、清空按钮 |
| 原乐句提示 | 每轮在音序器中最多听一次模糊回忆 |
| 暂停 / 继续 | Esc 或右上角暂停按钮 |
| 关闭音序器 | Esc 或 ×；保留本轮排列与已使用的提示状态 |
| 重开 | 暂停、失败、通关界面的重开按钮 |

三个平台从左到右为中、高、低。地面可跳上左右平台；中央最高平台只能从左侧平台跳上，从地面或右侧平台均不可达。平台是可从下方穿过的单向顶面。春季声音为春风、雨滴、嫩芽、鸟鸣；声音罐栏的显示顺序与答案独立。

## 三轮尝试与回忆机会

- 初始音符隐藏且无法拾取；按一次 F 显现本轮全部音符，重复 F 不会重置收集。
- 点击开场按钮自动播放一次**清晰主题**，不占答题窗口的三次模糊回忆机会。
- 本关共有三次还原尝试。每轮在音序器中最多听一次**模糊回忆**，点击后左上角立刻有一颗实心点变为空心。
- 若已经听过再答错，剩余圆点不会再重复扣一次。若没听就答错，本轮未用的圆点同样作废。
- 每次答错消耗一次尝试，清空排列、清空声音罐栏，将全部音符复位隐藏；需重新按 F、重新收集并返回回忆点。
- 关闭窗口、清空排列、暂停或停止试听都不会恢复本轮回忆额度。单只声音罐与当前排列可以反复试听。
- 三次失败后显示失败界面，可重新开始本关，重置三次机会并重新播放开场。
- 正确后冰雪消融、花草开放、藤蔓形成通路；向右走过夏季入口后显示完成界面。

本次明确新增的有限尝试、失败重新收集、开场与答题不同版本音频规则优先于策划案原来的无限尝试和保留收集规则。策划案中暂不实现跳跃等表述不会删除已有能力。对应范围见 [策划落地说明](docs/SPRING_DESIGN.md)。


构建输出位于 `dist/`，可静态托管；本地构建预览通常在 <http://127.0.0.1:4173/>。部署子路径时使用：
